# Deadline Math

Can a language model convert a published contest deadline ("Submissions close October 28, 2026 at 11:59 PM PT")
into the reader's local time? A benchmark built on [Kaggle Community Benchmarks](https://www.kaggle.com/benchmarks)
for the [DEV Kaggle Benchmarking Challenge](https://dev.to/challenges/kaggle-2026-09-23).

**Public benchmark:** https://www.kaggle.com/benchmarks/hugovalerrojas/deadline-mat

**Main finding:** when models fail, they fail by **exactly one hour**: they apply the usual offset during the weeks
when Europe and the US change clocks on different dates, or they add clock hours across a clock change. A
[pre-registered](docs/PREREGISTRATION.md) set of 50 trap/control pairs confirms it.

## What is here

| Path | What |
|---|---|
| `benchmark/deadline_math.py` | Cases, prompts, oracle and the Kaggle task. Importing it fails if any hand-written answer disagrees with `zoneinfo`. |
| `benchmark/kaggle/*.py` | The six self-contained files pushed to Kaggle (generated by `construir_kaggle.py`). |
| `benchmark/tests/` | 24 tests: oracle, an independent hand-written DST oracle for the 100 paired cases, parser, analysis. |
| `benchmark/kaggle_resultados.py` | Per-task tables from the downloaded runs, with the accepted task versions fixed. |
| `benchmark/analisis_pares.py` | The pre-registered analysis (Wilson, exact McNemar, bootstrap, sign test). |
| `benchmark/cifras_articulo.py` | Every number quoted in the article, computed from the data. |
| `benchmark/resultados/RESULTS.md` | **Final results in English**: pre-registered pairs, extension, 4-task cohort, repeatability. |
| `benchmark/resultados/kaggle/` | Raw runs downloaded from Kaggle (`kaggle b t download`), including full trajectories. |
| `benchmark/resultados/piloto-*.jsonl` | Local pilot runs through the same model proxy. |
| `docs/PREREGISTRATION.md` | Pre-registration (English translation) with deviations and execution log. |
| `docs/preregistro-original-es.md` | The authoritative Spanish original. |

Script docstrings and comments outside `deadline_math.py` are in Spanish (the author's working language).

## Reproduce

```bash
python -m venv .venv && .venv/Scripts/pip install kaggle-benchmarks pandas   # Windows paths; adapt on Linux/macOS
.venv/Scripts/python -m unittest discover -s benchmark/tests -v
.venv/Scripts/python benchmark/cifras_articulo.py
```

Running the tasks needs a Kaggle account with phone and identity verification and `kaggle benchmarks init`.
